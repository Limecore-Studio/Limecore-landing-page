# Limecore Site — Studio Landing Page

## Overview
Landing page for Limecore Studio. Plain HTML/CSS/JS — no framework, no build step. Single `index.html` + `/blog/` (posts in `blog/`, content in `content/`). Deployed on Vercel (static), auto-deploys from `main` (GitHub repo: see README).

## Rules
- Keep it dependency-free: no frameworks, no build step, no npm. Edits are direct HTML/CSS/JS.
- Screenshots live in the repo root (`Nexus_HQ_*`, `Limelog_*`, `StudyDesk_*`, etc.) — reference them, don't duplicate.
- Pushes to `main` deploy to production immediately. Confirm before pushing.
- Launch TODOs (domain migration, F-Droid badges) are tracked in `README.md` — update it when one lands.
- Style: dark premium, minimal — match the shipped aesthetic; no redesigns unasked.
